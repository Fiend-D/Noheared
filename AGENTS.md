# AGENTS.md

## Run

```bash
python main.py
```

## Dependencies

`requirements.txt` lists only `PyQt6`, but runtime also needs `pygame` and `numpy`. Generation scripts additionally need `pydub`, `edge-tts`, `Pillow`. All are installed in `.venv/`.

Two venv dirs exist at root: `.venv/` (likely active) and `venv/`. Activate before running.

## Project layout

```
main.py                  # entry point
unheared/
  ui/main_window.py      # PyQt6 UI (799 lines)
  audio/player.py        # pygame.mixer audio engine
  scene/map.py           # scene rendering, pathfinding (BFS), collision
  case/case.py           # loads cases from unheared/cases/*.json
  cases/case1-7.json     # 7 cases in Chinese
  audio/caseN/           # .wav files per case (mono, 24000 Hz resampled)
  resources/backgrounds/ # pre-rendered blueprint PNGs for cases 1-7
```

No `__init__.py` files in package directories (unusual for Python but intentional).

## Cases

- Cases 1–4: short (~120s). Cases 5–6: long (~1800s), 10 characters each. Case 7: long (~1680s), 8 characters.
- `case5.json` and `case6.json` are generated by `generate_case5.py` / `generate_case6.py`. `case7.json` is generated by `generate_case7.py`. These scripts output to the **root** directory — you must manually move the generated JSON to `unheared/cases/`.
- Case audio is generated by `generate_audio.py` (all cases), `generate_audio_case4.py`, or `generate_audio_case7.py` (single-case variants).

## Audio

- Mono-only (`pygame.mixer` limitation — `set_pan` is a no-op stub).
- Character audibility requires **same room area** + distance-based volume falloff (linear, radius 120).
- Footstep sounds are synthesized by `generate_footstep_sounds.py`.

## Testing & linting

None. No test framework, no linter, no typechecker, no CI, no pre-commit hooks.

## Git style

Conventional commits: `feat:`, `fix:`, etc. No commit signing.

## Case JSON format

Each case file contains: `name`, `scene` (areas, doors with connected_area_ids, optional floor), `characters` (color, positions with timestamps, movement types), `audio_tracks`, `dialogues` (subtitle segments with start/end), `questions`.
