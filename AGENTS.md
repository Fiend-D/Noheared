# AGENTS.md

## Layout

- `game/` — the Godot 4.7 project (GDScript, static typing). This is the actual game.
- `tools/` — Python content pipeline (`migrate_legacy_case.py`, `compose_case.py`, `pacing.py`, `tts_lines.py`, `art_sheets.py`, `furnish.py`, `fix_speech_timing.py`). Raw AI art sheets live in `tools/art_sources/`.
- `legacy/` — old PyQt6 + pygame implementation, kept for reference (code and case JSON only; its audio and `release/` are local-only, gitignored). Do not extend it.
- `docs/unheard-analysis.md` — gameplay analysis and design decisions.
- `docs/setup.md`, `docs/case-authoring.md`, `docs/packaging.md` — environment setup, making cases (incl. TTS), export / release.

## Godot

No Godot on PATH by default; a local binary lives at `~/.local/share/godot/Godot_v4.7.2-stable_linux.x86_64`.

```bash
godot --headless --path game --import                                        # after adding/changing assets
godot --headless --path game --script res://addons/case_editor/import_cli.gd  # case.json -> case.tres + map.tscn (+ validation)
cd game && godot --headless -s -d res://addons/gdUnit4/bin/GdUnitCmdTool.gd --ignoreHeadlessMode -a res://tests
```

`addons/gdUnit4/runtest.sh` fails in headless mode; call `GdUnitCmdTool.gd` directly as above.

## Architecture rules

- `TimelineClock` is the only time source. Systems read `clock.time` and must not keep per-frame state that affects results; seeking must give the same state as sequential playback (`tests/test_seek_consistency.gd`).
- Character positions come only from `TrackMath.sample(track, t)`. No runtime pathfinding or collision for characters.
- The listener is the exception: it walks in real time (not timeline time) with wall collision; walkable space is room interiors plus door passages (`CaseMap.is_walkable`), click-to-walk uses `CaseMap.route`. Map colours live in `MapStyle`, UI colours in `UiTheme`.
- Map art: `map.backdrop` is a tiled exterior texture (`map/backdrop.gdshader`), `CaseMap._draw` paints the building mass (rooms grown by `MASS_GROW` and merged); rooms draw a tiled floor material, walls come from the room polygon; doors draw textured thresholds and leaves; furniture is `Prop` nodes (`map.props` in JSON, sprites + `catalog.json` in `game/art/props/`). Blocking props stop the listener and click routes detour around them (AStarGrid2D per room, listener only). NPCs never path around furniture, so props must stay off character tracks — `tools/furnish.py` guarantees it and `CaseValidator` warns on "穿过家具".
- Spotlight lighting: `CaseMap.light_from(room)` sets per-room brightness / warm-vs-teal by acoustic cost (`MapStyle.LIGHT_LEVELS`, `map/lit.gdshader`). It's visual only and fades in real time like the listener.
- `PropCatalog` reads `catalog.json` only at import / in the editor; prop size, blocking and texture are baked into `map.tscn`. Re-import cases after changing the catalog.
- Audibility goes through `Acoustics` (room graph). Buses `Room` / `Muffled` / `Far` are created at runtime by `AudioBuses.setup()`; there is no `default_bus_layout.tres`.
- Scripts used by the editor plugin (data resources, `TrackMath`, `Acoustics`, `CaseValidator`, `CaseJson`, `CaseMap`, map nodes incl. `Prop` / `PropCatalog`, `UiTheme`, `CueScheduler`) must stay `@tool`, otherwise the editor gets placeholder instances.
- UI is built in code; scenes are minimal (`ui/main.tscn`). Flow: `TitleScreen` (menu only) → `CaseCabinet` (drawer of case files, dossier) → `Game`; leaving a case returns to the cabinet.
- Character tokens (`ActorDot`): grey silhouette + number badge until identified, then the portrait of the assigned identity (`CaseLibrary.portrait_for_name`) with a name ribbon. Portraits live in `game/art/portraits/<case>/<char id>.jpg`, posters in `game/art/posters/<case>.jpg`, both cut by `tools/art_sheets.py` (`PORTRAITS` maps sheet cells to characters).

## Case data

- Source of truth is `game/cases/<id>/case.json`. `case.tres` and `map.tscn` are generated by the import CLI — regenerate rather than hand-edit, or edit via the editor plugin and export back to JSON.
- Voice audio is one OGG per line under `game/cases/<id>/audio/`. Text in `（）` is a stage direction: shown in subtitles, never spoken.
- Cases 1, 2, 3, 8 and 9 are written as `game/cases/<id>/case.play` screenplays and compiled by `tools/compose_case.py`; for them the `.play` file is the source (recompiling overwrites everything in `case.json` except props / floor materials). Recompile after TTS so timings use the real durations; never run it while `tts_lines.py` is running.
- Cases 1–3 and 6–9 are voiced by `tools/tts_lines.py` (CosyVoice2); lines carry `"tts": "cosyvoice"`. Set `"tts_instruct": false` on a line if its stage direction leaks into the speech. Cases 1–3 have no portraits after the rewrite; unidentified and identified tokens both stay grey silhouettes until new sheets are cut.
- Committed: code, docs, `case.json`, and runtime assets (`game/cases/*/audio`, `game/audio`, generated `case.tres` / `map.tscn`, `*.import`). Not committed: `tools/voice_prompts/`, legacy recordings and builds, Godot caches. Don't add new generated-but-unneeded audio to git; extend `.gitignore` instead.
- Floors: rooms carry `floor`; legacy cases with stairs split floors at y=460.

## Python tools

- `tools/migrate_legacy_case.py` — stdlib + ffmpeg only. Needs the legacy recordings in `legacy/unheared/audio/`, which are not in git.
- `tools/art_sheets.py` / `tools/furnish.py` — system Python with Pillow, numpy, scipy (not in `.venv/`).
- `tools/compose_case.py` — stdlib + ffprobe; imports helpers from `tts_lines.py` and runs `pacing.py` (dead-air limits: no global silence > 20 s, ≥10 s gaps at most one per 5 min, opening ≤ 10 s, tail ≤ 15 s); pacing errors block writing `case.json`. `CaseValidator` mirrors the gap / opening / tail limits as WARNs.
- `tools/tts_lines.py` — default engine is CosyVoice2, which needs its own Python 3.10 env at `~/.local/share/unheard-tts/venv` (see README). `--engine edge` uses edge-tts from `.venv/`.
- `.venv/` (Python 3.14) has gdtoolkit and edge-tts.
